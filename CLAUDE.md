# AOMC Elytra Hunt

Static site: TypeScript, no framework. See `docs/development.md` to run it.

Before changing the interface (`index.html`, `src/style.css`, or anything in
`src/main.ts` that builds controls), read `docs/design.md` and follow it. Reuse
an existing pattern; if a new one is needed, add it to that file in the same
change.
